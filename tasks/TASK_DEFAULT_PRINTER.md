# タスク: 場面ごとの既定プリンター

`BRIEF.md` が契約。`docs/STATUS.md` を読むこと。
自分が書いた `docs/RESEARCH_FEATURES_ROUND3.md` の「4. 場所ごとの既定プリンター」を実装する。

## 作るもの

利用者が付けた場面（「自宅」「職場」など）を選ぶと、
**既にインストール済みの**プリンター1台を今回の既定にする。終わったら直前の既定へ戻す。

## やらないこと

- プリンターやドライバーを**追加しない**
- 印刷設定を一括変更しない
- **実際に印刷しない**
- 場所を GPS やネットワークから**自動推測しない**。利用者が明示的に選ぶ

## Windows が自動管理しているとき

Windows には「通常使うプリンターを Windows で管理する」設定がある。
**これが有効なときは変更しない。** 変えても Windows が上書きし直す。
有効かどうかを読み取り、有効なら「この設定が入っているので変更しません」と表示すること。

## 必ず守ること

- 適用前の既定プリンター名を保存し、**その名前へ戻す**。既定値を書かない
- 戻すとき、現在の既定が自分の適用値と違っていたら `ExternalConflict` で止める
- プリンター名は利用者が付けた名前で個人情報を含みうる。**ログに出さない**。
  画面には出してよいが、EVIDENCE 行には出さない
- 存在しないプリンターへ戻そうとしたときは、上書きせず「戻せていない」と残す

## 検証

**「設定した」を「既定になった」の証明にしない。**

`#[ignore]` の実機テストで、次を確認して `EVIDENCE:` 行に出すこと。

1. 現在の既定プリンターを読む
2. Windows 自動管理が有効なら、**そこで「測れない」と出して終わる**（変更しない）
3. 無効なら、別のインストール済みプリンターへ変更する
4. **読み直して**既定が変わったことを確認する
5. 元へ戻す
6. **もう一度読み直して**元の既定に戻ったことを確認する

プリンターが1台しか無い環境では、**変更先が無いので「測れない」と出す**こと。
同じ値を書いて同じ値が返っても何も証明していない。このセッションで電源モードが同じ間違いをしている。

名前そのものは出さず、**ハッシュか「同一/別」の判定だけ**を EVIDENCE に出すこと。
