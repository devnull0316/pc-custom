# タスク: そもそもタスクバーのピクセルが取れているのか

`BRIEF.md` と `docs/RULES.md` を読め。

## 分かっていること

タスクバーのピクセル計器が、**既知の変化に対して delta=0.00 を返す。**
メモ帳を2つ起動しても、透明度を切り替えても、数値が1ミリも動かない。

3つの観測方法を試して全部だめだった。**計器の作り方ではなく、
土台の `GetPixel` が機能していない可能性がある。**

## 確かめること（この順で）

1. **`GetPixel` はタスクバー上で有効な値を返しているか**
   - `taskbar_pixel_stats()` が集めている 200 点の**生の値**をそのまま出せ
   - 全部同じ値なら、それは「読めていない」
   - `CLR_INVALID` が混じっていないか
   - **画面の別の場所**（デスクトップ中央など）でも同じことをして比べろ。
     そちらで値がばらつくなら、タスクバーだけの問題

2. **DWM のせいか**
   Windows 11 のタスクバーは DWM が合成する。
   画面 DC からの `GetPixel` では、合成後ではなく**古い内容や黒**が返ることがある。
   - `GetDC(NULL)` ではなく `GetWindowDC(taskbar)` や
     `PrintWindow` / `BitBlt` での取得を試せ
   - どれか1つでも既知の変化を捉えられたら、それが答え

3. **座標は合っているか**
   高 DPI で、`GetWindowRect` の値と物理ピクセルがずれる可能性。
   - サンプリング座標が本当にタスクバーの上か、`WindowFromPoint` で確かめろ

## 出すもの

**判定を出せ。** 次のどれか。

- **タスクバーのピクセルは取得できる**（どの方法でか、既知の変化で delta が出た証拠つき）
  → `taskbar_pixel_stats()` をその方法へ直せ
- **どの方法でも取得できない**
  → ピクセル観測は**この用途では使えない**と結論し、
     `docs/DISPLAY_ONLY_TRIAGE.md` と `docs/STATUS.md` に記録しろ。
     保留5件の「ピクセルで測る」選択肢を閉じろ

**どちらでもよい。決着をつけることが目的。**

## 絶対に守ること

- 起動したアプリは閉じろ。設定は戻せ
- `EVIDENCE:` 行に**生の値のサンプル**を含めろ（先頭10点など）
- ウィンドウタイトルを出すな
