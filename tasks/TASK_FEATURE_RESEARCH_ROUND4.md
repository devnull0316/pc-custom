## 探すもの

**4回目なので、これまでと違う場所を探せ。**

1. **既に持っている部品の組み合わせで生まれるもの**
   新しい Windows API が要らないなら、実装が安く確実。
   モード・タイムライン・照合・窓配置・監視のどれかを組み合わせて何ができるか。

2. **利用者が「戻せる」ことを本当に必要とする場面**
   この製品の芯は復元。**復元が主役になる機能**は何か。

3. **Windows 11 の新しめの機能で、設定が分かりにくいもの**
   2025年以降に入った機能で、利用者が設定場所を探している声があるもの。

4. **面白い側**（半分はこちらへ）
   使っていて嬉しい、PC が自分の道具だと感じられる方向。
   ただし面白さを口実に BRIEF の制約を緩めるな。

## 各件に書くこと

1. 何ができるようになるか（利用者の言葉で。API 名を使うな）
2. なぜ必要か（**実在する声を URL と日付つきで。票数や反応数も**）
3. 既存ツールはどうしているか、なぜ足りないか
4. Windows のどの**公開**手段で実現できるか（**文書化された API の URL**）
5. 元に戻せるか（戻せないならそう書け。戻せるふりをするな）
6. 実装の難しさと、いちばん危ないところ
7. この製品の芯と噛み合う理由

## 絶対に守ること

- **需要を盛るな。** 票数が小さいなら「需要は限定的」と書け
- **効果を約束するな。** 速くなる／FPS／遅延 は書くな
- BRIEF の禁止事項に触れる案は最初から出すな
- **web検索を使って実在の声と公式文書を集めろ。** 記憶で書くな
