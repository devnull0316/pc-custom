# タスク: 2モデルが出した指摘を検証して直す

`BRIEF.md` と `docs/RULES.md` を読め。

指摘の一覧は、このタスクと一緒に渡された `findings-to-verify.md` にある。

## 手順

### 1. まず否認する

**引用された行が実在するか**を最初に確かめろ。存在しない行を根拠にした指摘が、
このプロジェクトで最も多かった不良の形。実在しなければ**その指摘は捨てろ。**

実在したら、次にその指摘が**本当に起きうるか**を確かめろ。
- 別の層で既に防いでいないか
- その入力経路が実際に到達可能か
- 意図した設計として書かれていないか（コメントを読め）

**確かめられないなら直すな。** 「念のため直す」をするな。

### 2. 残ったものだけ直す

直した各件について、**それが直ったことを示すテストを足せ。**
テストが無い修正は、次の版で戻る。

### 3. 報告

指摘ごとに「実在した/しなかった」「本物だった/でなかった」「直した/直さなかった」を書け。
**直さなかった理由も書け。**
