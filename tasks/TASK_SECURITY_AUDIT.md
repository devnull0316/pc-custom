# タスク: 攻撃されたときを監査する

`BRIEF.md` と `docs/RULES.md` を読め。**`docs/STATUS.md` は読まなくてよい。**

## なぜ

このアプリは**利用者のPCの設定を書き換え、プロセスを起動し、ファイルを消す**。
壊れ方ではなく、**悪意ある入力や環境に対してどう振る舞うか**は一度も見ていない。

昇格しない・スクリプトを実行しない・未知バイナリを落とさない、は BRIEF が禁じている。
そこは守られている前提で、**それ以外の穴**を探せ。

## 探すもの

1. **画面から渡る値**
   - `src-tauri/src/commands.rs` の各コマンドが受け取る文字列・数値・パス
   - 長さ・文字種・範囲の検証が無いまま Windows API やファイル操作へ渡る経路
   - パス結合で `..` や絶対パスを弾いているか（`src-tauri/src/config_snapshot.rs`、
     `src-tauri/src/game_profile/store.rs`、設定の取り込み）

2. **外から来るデータ**
   - 取り込む設定ファイル（`config_snapshot`）が、信用できない JSON でも安全か
   - 深いネスト・巨大な配列・巨大な文字列で、メモリや時間を食い潰さないか
   - 取り込んだ値がそのまま Windows API や画面へ流れていないか

3. **プロセスとファイル**
   - 起動する実行ファイルのパスが、**書き換えられうる場所**を指していないか
   - シンボリックリンク・ジャンクションを辿って別の場所を消す経路はないか
     （一時ファイル削除、設定ディレクトリ）
   - `%PATH%` や作業ディレクトリに依存して DLL や exe を拾う箇所はないか

4. **秘密と個人情報**
   - ログ・エラー・EVIDENCE・耐久記録に、ファイル名・ウィンドウタイトル・
     ユーザー名・接続先・プリンター名が漏れていないか
   - 診断用に出す情報が、そのまま個人を特定できる形になっていないか

5. **権限**
   - 昇格が必要な操作を、昇格せずに試みて中途半端に終わる経路はないか
   - 他ユーザーのセッションやプロセスへ触れる経路はないか

## 出し方

FINDING
file: <repo相対パス>:<行番号>
quote: <その行の実際の中身をそのまま1行>
what: <何が起きるか。1文>
how: <どんな入力・環境でか。具体的に>
severity: high|medium|low
END

**引用する前に、その行が実在することを確かめろ。**
**コードを1行も変更するな。** 攻撃コードを書くな。無ければ NO FINDINGS。
