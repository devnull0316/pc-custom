# タスク: 毎回読ませている文書を減らす

## 背景（実測）

`docs/STATUS.md` は 71,304文字（約31,000トークン）。
codex と Gemini へ作業を投げるたびに、`BRIEF.md` と合わせてこれを読ませている。
1日12回投げれば約37万トークンが「同じ失敗記録の読み直し」に消える。
実際にこれでモデル側のクォータが尽きた。

## やること2つ

### 1. まず監査（報告のみ）

**毎回の読み込みに乗っている無駄**を洗い出せ。次を見ろ。

- `docs/STATUS.md` の中で、同じ規則が別の節に重複して書かれていないか
- `BRIEF.md` と `docs/STATUS.md` で重複している内容
- `tasks/*.md` に、毎回書き写している同じ制約（BRIEF に既にあるもの）
- `docs/RESEARCH_FEATURES*.md` 3本の間の重複
- その他、読ませる必要のない分量

**削れる文字数を数字で出せ。** 推測でなく実際に数えろ。

### 2. `docs/STATUS.md` を2つに分ける

- `docs/RULES.md` — **次の作業で必ず要る規則だけ。** 短く。
  例:「見えないは透過ではない」「読めたは変わったではない」
  「設定値の readback は効果の証拠にならない」「0件が出たら計器を先に疑う」
- `docs/STATUS.md` — 経緯の記録。**全文をそのまま残す。**
  先頭に `RULES.md` への参照を1行置く。

以後、作業を投げるときは `BRIEF.md` と `RULES.md` だけ読ませ、
`STATUS.md` は必要なときだけ引く。

## 絶対に守ること

- **規則を1つも落とすな。** 現在 56 節ある。
  節見出しはすべて `STATUS.md` に残したまま、規則だけ `RULES.md` へ**抜き書き**する
  （移動ではなく抽出。`STATUS.md` の本文は削らない）
- `RULES.md` の各項目には、**元の節見出しを併記**しろ。どこから来た規則か辿れるように
- 事実を要約で歪めるな。数値や `EVIDENCE:` 行を書き換えるな
- コードに触るな。`docs/` と `tasks/` だけ

## 完了条件

- `docs/RULES.md` が新規にあること
- `docs/STATUS.md` の**節見出し 56 個がすべて残っている**こと
- `RULES.md` が 8,000文字以下であること
- 監査の結果（削れる文字数の一覧）を報告に含めること
- `cargo test --lib` と `npm run build` が通ること（壊していないことの確認）
