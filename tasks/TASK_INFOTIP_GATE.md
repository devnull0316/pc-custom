### 外からの確認

値が変わっただけでは「ポップアップが消えた」とは言えない。
新しく開いた Explorer の窓で、実際にツールチップが出るか出ないかを観測すること。

- 自分で作った一意な名前のフォルダーと、自分で作ったファイルだけを対象にする
- **利用者の窓を閉じない。利用者のファイルを触らない**
- 観測は UI Automation でよい。`src-tauri/src/windows/ui_probe.rs` に既存の作法がある
- 後始末はすべて `Drop` で。作ったフォルダーもファイルも残さない

**設定オフのときとオンのときで、観測結果が違うことを数値で示せなければ昇格しない。**

`docs/STATUS.md` には UI Automation で測れなかった前例が複数ある。
測れなかったら「測れなかった」と書く。それも成果。

## 必ず守ること

- 検証中に変えた設定は**必ず元へ戻す**。panic しても戻るよう `Drop` を使う
- ホバーのために**マウスカーソルを動かす必要があるなら、動かす前後で元の位置へ戻す**。
  戻せないなら、カーソルを動かさない方法を探すか、測れないと結論する
- 「tooltip がすべて消える」とは書かない。対象はファイル／フォルダーの説明ポップアップだけ
- registry を直接書かない

## 結論の書き方

`docs/STATUS.md` の末尾に節を足す。

- 何を測ったか
- 数値（`EVIDENCE:` 行をそのまま貼る）
- **昇格してよいか、してはいけないか、まだ分からないか**
- そう判断した理由

昇格してよい場合にだけ Action を実装する。出なければ**実装しない**。
