# タスク: 測る前にタスクバーが見えていることを確かめてから、測る

`BRIEF.md` と `docs/RULES.md` を読め。
`docs/DISPLAY_ONLY_TRIAGE.md` と `docs/STATUS.md` の**訂正の節**を必ず読め。

## 分かっていること

- タスクバーのピクセルは**取得できる**。`GetDC(NULL)` / `PrintWindow` / `BitBlt` の3つが機能する
- ただし**ある実行では全点が同じ値になり、`delta=0.00` が出る**。
  タスクバーが他の窓に覆われている、フレームが未合成、などが原因と思われる
- その1回を根拠に「ピクセルは使えない」と結論しかけた。**再現しなかった**

## やること

### 1. 前提条件を作る

サンプリングの直前に、**タスクバーが実際に見えていること**を確かめる関数を足せ。

判定の候補（**どれでもよい。効くものを選び、選んだ理由を書け**）:
- 取得した点の**分散がゼロでない**こと（全点同じ値なら覆われている）
- `WindowFromPoint` でサンプリング座標が `Shell_TrayWnd` に属すること
- タスクバーが最前面か（`GetForegroundWindow` が全画面の窓でないこと）

前提が満たされなければ、**測らずに `measured=false reason=taskbar_not_visible` を出せ。**
覆われた状態で測って「変わらなかった」と言うのが、今回の失敗そのもの。

### 2. 前提条件つきで `button_grouping` を測り直せ

手順は前と同じ。ただし各観測の前に上の確認を通せ。

1. 前提を確認 → メモ帳0個で記録
2. 前提を確認 → メモ帳2個で記録 → **既知の変化で差が出るか（校正）**
3. 校正が通ったら、設定を変えて測る
4. 戻して再確認

**校正が通らなければ、そこで止まって `measured=false` を出せ。**
3回以上試して通らないなら、**その旨を記録して終われ。閉じるな。**

### 3. 判定

- 差が出た → **昇格候補**として報告
- 差が出なかった（校正は通った）→ 「実測して効かない」へ格上げ
- 校正が通らない → 保留のまま。**試した前提条件と結果を記録しろ**

## 絶対に守ること

- メモ帳は必ず閉じろ。設定は必ず戻せ
- `EVIDENCE:` に**前提確認の結果**と**校正の数値**を必ず含めろ
- 1回の観測で結論を出すな。**同じ測定を2回走らせて、同じ結果になることを確かめろ**
