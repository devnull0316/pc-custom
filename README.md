# PCカスタム

Windows 11 の設定を、設定名ではなく「やりたいこと」から選んで変えるアプリです。
変えたものは 1 件ずつ元に戻せます。

日本語のみ。Windows 11 専用。

---

## どういうものか

Windows の設定は、名前を知らないと辿り着けません。「エクスプローラーでファイルの拡張子を
見えるようにしたい」と思っても、それが「登録されている拡張子は表示しない」という
二重否定のチェックボックスだと知らなければ探せません。

このアプリは逆から入ります。「ファイルの種類を見分けたい」を選ぶと、何が変わるのか、
今どうなっているのか、変えたあとどうなるのか、元に戻せるのかを先に見せます。
納得してから適用します。

適用した変更は履歴に 1 件ずつ残り、それぞれ独立して戻せます。まとめて戻す必要はありません。

## どういうものではないか

レジストリいじりツールでも、PC 高速化ツールでもありません。

「FPS が上がる」「入力遅延がゼロになる」といった、根拠を示せない主張はしません。
Microsoft Defender や Windows ファイアウォールや Windows Update を止める機能も入れません。
サービスの一括停止も、ページファイルの無効化も、BCD や HPET の変更もしません。
アンチチートが監視しているプロセスには近づきません。

## 正直に言っておくこと

**登録されている 69 項目のうち、39 項目は表示専用です。変更できません。**

理由は、変更しても Windows が従わないことを実測したからです。
たとえばタスクバーの配置は、レジストリに値を書いてもエクスプローラーを再起動するまで
画面は動きません。UI Automation で実際のタスクバーを外から読み、6 秒待っても
スタートボタンが動かないことを確認しました。

こういう項目を「変更できます」として出せば、押しても何も起きないものを
押させることになります。だから表示専用にしてあります。画面には
「Windows 設定案内」と出て、Windows 自身の設定画面へ案内します。

内訳は次のとおりです。

| 種別 | 件数 | 内容 |
| --- | --- | --- |
| 変更できる | 13 | 実際に設定を変えられ、1 件ずつ元に戻せる |
| 確認するだけ | 9 | 現在の状態を読むだけで、何も変えない |
| 表示専用 | 39 | 書いても画面が変わらないと実測したもの |
| Windows の設定画面へ案内 | 6 | Windows 自身でしか変えられないもの |

（残る 1 件は、元に戻せない性質の操作を別扱いにしているもの）

この数字は減る見込みです。実際、当初 42 項目だったものが 39 項目になりました。
減らすには、その項目について「書いたら実際に画面が変わる」ことを実機で確認する必要があります。

一部の設定は、値を書いただけでは画面が変わらず、エクスプローラーを再起動して初めて反映されます。
そういう項目にはアプリ内で再起動ボタンが出ます。押す前に何が起きるかを全部表示します。

## 安全側の設計

このアプリは Windows の設定を書き換えます。壊さないために、いくつか決めごとがあります。

**管理者権限で動かしません。** 全体が現在のユーザー権限（`asInvoker`）で動きます。
昇格したヘルパーは同梱していません。

**元に戻すために、値だけでなく「無かったこと」も保存します。** レジストリのバックアップには、
キーが存在したか、値が存在したか、値の型は何か、元のバイト列、適用したバイト列を記録します。
元が「未設定」だった項目は、既定値ではなく未設定へ戻します。

**他のアプリが変えた設定は上書きしません。** 適用後に第三者が同じ値を変えていた場合、
ロールバックは実行されず「適用値と異なる現在状態を検出したため、自動では上書きしません」
と表示して止まります。

**知らない Windows ビルドでは動きません。** 検証していないビルドでは、推測で適用せず
復旧モードに入ります。

**PowerShell の文字列を実行しません。** 画面から渡せるのは登録済みの Action ID と
検証済みのパラメーターだけです。ユーザー入力をコマンド行へ連結する経路はありません。

## 動かすには

Windows 11、Rust 1.82 以上、Node.js 20 以上。

```bash
npm install
npm run tauri dev
```

配布用のインストーラーを作る場合。

```bash
npm run tauri build
```

`src-tauri/target/release/bundle/nsis/` に per-user インストーラーができます。
管理者権限は要りません。

## 検証について

このプロジェクトで一番高くついた失敗は、**テストが全部通っているのに何もしていない機能を
6 つ出荷した**ことです。レジストリの往復テストは「意図した値を書けた」ことしか証明せず、
「Windows がそれで何かしたか」は何も証明しません。

そのため、変更を伴う機能は書いた経路とは別の手段で結果を確認しています。
UI Automation で実際のタスクバーやエクスプローラーの中身を外から読み、
ウィンドウ配置は `GetWindowRect` で座標を読み直します。
確認できないものは表示専用に落とします。

```bash
cargo test --lib                    # 229 件
cargo test --lib -- --ignored       # 実機を触る 27 件
```

実機テストは自分で作ったウィンドウだけを操作し、変更したレジストリは必ず元へ戻します。
既存の利用者ウィンドウには触れません。
